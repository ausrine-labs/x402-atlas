How to read these numbers

  • Source: the public x402 discovery registry, photographed once a day. A seller missing from that registry is missing here; that is not the same as not selling.
  • “Payers” are endpoint counts summed: a wallet paying two endpoints counts twice. A wallet is not an agent.
  • “Money” is paid calls times list price. It is an estimate, not settled revenue, and it misleads for sellers whose price varies per call.
  • Movement is the change in a rolling 30-day total between stored days, not a daily count.
  • Self-dealing is not filtered. A seller can pay its own endpoint, and those calls count here like any others. A high rank is a count of paid calls, not a judgement that a service is good, safe or real.
